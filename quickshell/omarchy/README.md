# NixOS Omarchy Quickshell

This directory contains an original, small Quickshell implementation for this
repository. Its one-process shell architecture, bar composition, interaction
model, and Catppuccin palette are inspired by
[Omarchy](https://github.com/basecamp/omarchy). It is not a copy of Omarchy's
shell and does not attempt to provide Omarchy's full plugin or command suite.
